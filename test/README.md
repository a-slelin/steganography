## 3. Конфигурация запуска

### Команды запуска тестов

```bash
# Полный прогон всех тестов (использован при данном тестировании)
pytest tests.py -v

# Только unit-тесты
pytest tests.py -v -m unit

# Только UI-тесты
pytest tests.py -v -m ui

# Только интеграционные тесты
pytest tests.py -v -m integration

# Только граничные случаи
pytest tests.py -v -m edge_cases

# Только тесты производительности
pytest tests.py -v -m performance

# HTML-отчёт о результатах тестирования
pytest tests.py --html=test/html-report.html --self-contained-html

# Отчёт о покрытии кода (HTML + терминал)
pytest tests.py --cov=. --cov-report=html:test/htmlcov --cov-report=term
```

### Зарегистрированные маркеры

| Маркер                     | Описание                                      |
|----------------------------|-----------------------------------------------|
| `@pytest.mark.unit`        | Юнит-тесты отдельных функций без зависимостей |
| `@pytest.mark.ui`          | Тесты пользовательского интерфейса с PyQt5    |
| `@pytest.mark.integration` | Сквозные интеграционные тесты                 |
| `@pytest.mark.edge_cases`  | Граничные и нетипичные входные данные         |
| `@pytest.mark.performance` | Тесты быстродействия и временны́х ограничений |

## 4. Описание фикстур

Фикстуры обеспечивают изолированный, воспроизводимый контекст для каждого теста.

| Фикстура               |   Scope    | Описание                                                                                                                           | Используется в |
|------------------------|:----------:|------------------------------------------------------------------------------------------------------------------------------------|----------------|
| `qapp`                 | `session`  | Единственный экземпляр `QApplication` для всей сессии. Создаётся один раз и переиспользуется.                                      | Все UI-тесты   |
| `window`               | `function` | Свежий экземпляр `SteganoWindow` для каждого теста. После теста окно закрывается. Гарантирует изоляцию состояния.                  | Группы 3–10    |
| `palette_256`          | `function` | Список из 256 значений `QRgb` в виде равномерной серой шкалы `(i, i, i)`. Базовая палитра для большинства тестов LSB.              | Группы 1–2     |
| `palette_small`        | `function` | Список из 8 значений `QRgb`. Ёмкость: 24 бита = 3 байта (из которых 2 занимает заголовок). Применяется для тестов «не помещается». | Группы 2, 5    |
| `indexed8_image_256`   | `function` | `QImage` размером 10×10 пикселей, `Format_Indexed8`, 256 цветов, все пиксели = индекс 0.                                           | Группы 3–11    |
| `indexed8_image_small` | `function` | `QImage` размером 4×4, `Format_Indexed8`, 8 цветов.                                                                                | Группы 5, 9    |
| `tmp_png`              | `function` | Временный PNG-файл на диске (создаётся из `indexed8_image_256`). Автоудаляется после теста через `tmp_path`.                       | Группы 7–8     |

### Вспомогательные функции тестового модуля

```
make_indexed8(width, height, num_colors) → QImage
```

Создаёт тестовое палитровое изображение заданных параметров. Используется там, где нужен нестандартный размер или число
цветов.

```
lsb_embed_raw(palette, message) → List[int]
```

«Чистая» реализация алгоритма встраивания LSB — без Qt-интерфейса, без GUI. Применяется для верификации логики алгоритма
в изоляции от интерфейсного кода.

```
lsb_extract_raw(palette) → str
```

«Чистая» реализация алгоритма извлечения LSB. Используется для проверки содержимого палитры напрямую, минуя интерфейсный
слой.

### ✅ Заключение

Приложение **PNG LSB-Стеганография** (версия 1.0) прошло полный цикл автоматического тестирования. По
результатам 139 тестов в 12 группах:

- **Корректность алгоритма LSB подтверждена** — встроенное сообщение извлекается без потерь для всех протестированных
  типов данных (ASCII, кириллица, спецсимволы, переносы строк).
- **Инвариант неизменности оригинала соблюдается** — встраивание работает с копией, исходное изображение не
  затрагивается.
- **Персистентность данных обеспечена** — LSB-биты корректно сохраняются в PNG-файле и восстанавливаются после
  перезагрузки.
- **Управление состоянием UI корректно** — кнопки активируются/блокируются строго в соответствии с бизнес-логикой.
- **Обработка ошибок надёжна** — приложение не падает ни при одном из протестированных некорректных вводов.
- **Производительность приемлема** — все операции выполняются в единицы миллисекунд.

### 📌 Рекомендации для следующей версии

- Добавить тест с повреждённым PNG-файлом.

- Ввести явное предупреждение при автоконвертации RGB→Indexed8.

**Низкий приоритет:**

- Заменить фиксированные временны́е пороги в performance-тестах на относительные.
