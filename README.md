# Учебный проект стеганографии 💥 для .png-файлов

Проект представляет собой кроссплатформенное десктопное 👩🏻‍💻 приложение, реализующее методы 💎 **стеганографии** 💎 для
сокрытия 🔐 текстовой информации в **PNG**-изображениях 🎨. Программа позволяет пользователю незаметно встраивать
сообщения в цифровые изображения и извлекать их без видимого ухудшения качества картинки. Приложение разработано в
образовательных 🎓 целях для демонстрации принципов работы **стеганографии**, обработки изображений и создания
**GUI**-приложений на **Python** 🐍.

## Цели 🎯

**1)** Изучение стеганографических методов 📎 – на практике реализовать метод наименее значащих битов (**LSB**)
для сокрытия данных 🔒 в растровых изображениях 🎨.

**2)** Разработка полноценного GUI-приложения 🤩 – создать удобный интерфейс пользователя 🤳 с использованием **PyQt5**
для шифрования/дешифрования 🔑 сообщений.

**3)** Обеспечение кроссплатформенности 📥 – приложение должно работать на **Windows** и **Linux**, а также
поставляться в виде самодостаточного .exe или бинарного файла 💾.

**4)** Формирование навыков упаковки и дистрибуции 🔧 – научиться собирать проект 🔨 в единый исполняемый файл с
помощью **PyInstaller**.

**5)** Визуальное сравнение 📏 – дать пользователю возможность сравнить исходное и итоговое изображение
(с встроенным сообщением) для оценки 🏆 качества стеганографии.

## Структура 📂

Проект состоит из нескольких частей:

* **main.py** 🚀 - основная программа проекта (десктопное приложение);
* **linux/** 📥 - бинарный файл для Linux OS;
* **win/** 📥 - .exe-файл для Windows OS;
* **utility/** 📒 - вспомогательные файлы;
* **tests.py** 📊 - файл, используемый для тестирования приложения;
* **images/** 🎨 - некоторые изображения для работы с приложением.

## Требования 📍

Для разработки приложения используется язык программирования **Python** 🐍 версии **3.13**.

Необходимо установить некоторые [📚 библиотеки](requirements.txt) с помощью **pip** версии **26.1.1**:

```shell
# Создаём виртуальное окружение
python -m venv .venv;

# Активируем виртуальное окружение
.venv\Scripts\activate;

# Устанавливаем все необходимые библиотеки
pip install -r requirements.txt;
```

## Запуск 🚀

Для запуска приложения необходимо выполнить следующее:

```shell
# Активируем виртуальное окружение
.venv\Scripts\activate;

# Иногда для корректного запуска необходимо
# указать временную переменную на плагины Qt5
$env:QT_QPA_PLATFORM_PLUGIN_PATH = "<путь к проекту>\.venv\Lib\site-packages\PyQt5\Qt5\plugins"

# Запускаем десктопное приложение
python main.py;
```

Для создания исполняемого **.exe**-файла под **Windows OS** можно сделать следующее:

```shell
# Активируем виртуальное окружение
.venv\Scripts\activate;

# Создаём .exe-файл
pyinstaller --noconsole --onefile `
            --name "Steganography" `
            --collect-all PyQt5 `
            --distpath win main.py;

# Удаляем ненужные временные файлы
rm -rf build/;
rm -f Steganography.spec;

# Запускаем .exe-файл
win\Steganography;
```

Аналогичные действия делаются для **Linux OS**:

```shell
# Активируем виртуальное окружение
source .venv/bin/activate

# Создаём бинарный файл
pyinstaller --noconsole --onefile \
            --name "Steganography" \
            --collect-all PyQt5 \
            --distpath linux main.py

# Удаляем ненужные временные файлы
rm -rf build/
rm -f Steganography.spec

# Запускаем бинарный файл
./linux/Steganography;
```
