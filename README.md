## Запуск проекта

```shell
# Скачиваем необходимую библиотеку
pip install pyqt5;

# Запускаем десктопное приложение
python main.py;
```

Для создания исполняемых файлов под Windows можно сделать следующее:

```shell
# Устанавливаем упаковщик
pip install pyinstaller;

# Создаём .exe файл
pyinstaller --onefile --name "Stenography" main.py;
```

Аналогичное действие делается для Linux OS в их среде. В данном случае я решил ускорить работу, используя докер
контейнер.
